# SQL Data Warehouse Project

A practical project to build a complete Data Warehouse, covering database setup, ETL processes, data modeling, and analytics.

## 🚀 Introduction
This project was created to learn and practically apply core Data Engineering concepts. Through this repository, you will learn how to:
* Set up and manage a database using **SQL Server**.
* Build a data model (Data Modeling) utilizing Fact and Dimension tables (Star Schema).
* Implement **ETL (Extract, Transform, Load)** processes to clean and load data into the warehouse.
* Query and analyze data (Analytics) for Business Intelligence (BI) reporting.

## 📂 Directory Structure
* `/dataset`: Contains raw data files in `.csv` or `.json` format.
* `/sql_scripts`:
  * `01_create_tables.sql`: Script to initialize the Fact and Dimension tables.
  * `02_etl_process.sql`: Script for data cleaning and loading.
  * `03_analytics_queries.sql`: Analytical queries used for reporting.
* `/docs`: Contains images of the Data Warehouse's ERD (Entity-Relationship Diagram) design.
